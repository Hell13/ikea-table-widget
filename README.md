# Виджет «Стол» для macOS

Управление столом с Bluetooth-пультом Linak DPG1C (IKEA IDÅSEN и похожие).

- **Стол.app** — фоновое приложение без иконки. Держит Bluetooth, запускается при входе в систему.
- **Виджет «Стол»** — высота, статус, ▲/▼ (шаг 5 см), кнопки сохранённых позиций.
  Позиции меняются через «Изменить виджет» (правый клик по виджету).

## Сборка
1. Установить Xcode из App Store и `brew install xcodegen`.
2. В этой папке: `xcodegen`, затем открыть `DeskWidget.xcodeproj`.
3. В обоих таргетах: Signing & Capabilities → Team = ваш Apple ID.
4. Запустить схему DeskAgent (⌘R). Разрешить Bluetooth.
5. Первое сопряжение: зажать кнопку Bluetooth на пульте ~3 с, подтвердить на Маке.
   Телефонное приложение при этом должно быть отключено от стола.
6. Правый клик по рабочему столу → «Изменить виджеты» → «Стол».
